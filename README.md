# 미니게임 천국

친구들과 함께 하는 미니게임 모음입니다. 혼자 하는 게임 40종과 같이 하는 게임 47종이 들어 있어요.
(같은 와이파이는 물론, `start-online.bat` 으로 인터넷 주소를 만들면 다른 곳의 친구와도 할 수 있어요.)
**v8부터 얼굴로 회원가입 · 로그인**하고, 게임 기록 · 레벨 · 친구 · 방 초대 · 랭킹을 쓸 수 있어요.
**v9부터** 휴대폰 · 폴드 · 태블릿 · 노트북 어디서나 게임이 한 화면에 들어오고, 열린 방 목록 · 한 판 더 · 오늘의 미션 · 프로필 카드가 생겼어요.
**v10부터** 운영자가 전체 공지 · 업데이트 예고를 보낼 수 있고(운영자 지정 · 관리), 버그 · 불편 신고함이 생겼어요. 다른 앱에 갔다 와도 3분 안에 돌아오면 하던 게임을 이어서 해요.
**v10.1** 고스톱(2명은 맞고) · 체스를 싱글 · 멀티 모두 추가했어요.
**v11** 스도쿠 · 노노그램(싱글 · 같은 퍼즐 대결)을 추가하고, 모든 게임에 **게임 설명서**(핵심만 쏙 → 자세한 설명)를, 규칙이 어려운 게임 5종에는 실제 판에서 배우는 **따라 하기**를 넣었어요.
**v11.1** 드리프트 카트를 휴대폰 · 태블릿에서 **조이스틱**으로 조종해요 (왼손 엄지 조이스틱 · 오른손 엄지 버튼).
**v12.0** 점프 어드벤처 · 총알피하기 · 점프 배구도 **조이스틱**, 핑퐁이 훨씬 **빨라지고**, 고스톱 · 섯다에 **전통 화투 그림**, 위쪽 메뉴를 **하나로 정리**(소리 · 다크 모드 · 신고 · 요청 · 패치 노트), **버전 표시 · 패치 노트**가 생겼어요.
**v12.1** 고스톱 · 섯다 화투가 **진짜 한국 화투 그림** 그대로(光 · 홍단 · 청단 글씨까지)가 되고, 고스톱의 **먹은 패가 훨씬 크게** 보여요. 넓던 기록 칸은 **[기록] 버튼**으로 옮겼어요.
**v12.2** 10레벨마다 바뀌는 **레벨 테두리**(새싹 → … → 레전드)와 **칭호 37개**(판수 · 승리 · 연승 · 출석 · 친구 · 게임별 …), 새 테두리 · 칭호 **축하 화면**과 친구 축하가 생겼어요.

## 실행 방법
1. Node.js(LTS)를 설치합니다: https://nodejs.org
2. `start.bat`을 더블클릭합니다. 처음 실행할 때는 필요한 부품을 자동으로 설치합니다.
3. 브라우저에서 `http://localhost:3000`을 엽니다. 친구는 서버 창에 나온 "같은 와이파이" 주소로 들어오면 됩니다.

### 🌍 다른 곳에 있는 친구와 하기
- **`start-online.bat`** 을 더블클릭하면 `https://xxxx.trycloudflare.com` 같은 인터넷 주소가 생겨요. (내 컴퓨터가 켜져 있는 동안만)
- **24시간 켜 두려면** GitHub(GitHub Desktop) + Render(GitHub 로그인)에 올리세요. 잠들지 않게 하는 설정까지 들어 있어요. → **`DEPLOY.md` 방법 2**
- 대기실의 **📋 초대 링크 복사** 버튼으로 받은 링크를 친구가 누르면 그 방으로 바로 들어와요.

## 👤 얼굴 로그인 · 기록 · 친구 (v8)
**영천GO 키오스크와 같은 방식**으로 얼굴을 알아봐요.
1. 얼굴 검출 **SCRFD(det_500m)** 로 얼굴 상자와 눈 · 코 · 입꼬리 5점을 찾고, 정면이 아니거나 너무 작은 얼굴은 버려요.
2. 5점을 기준으로 얼굴을 112×112 로 반듯하게 맞춰 자른 뒤 **ArcFace MobileFaceNet(w600k_mbf)** 으로 특징값 512개를 만들어요.
3. **가입**: 여러 장면(8장)의 특징값 평균만 저장해요. 이미 가입된 얼굴(유사도 0.45 이상)이면 다시 가입할 수 없어요.
4. **로그인**: 가장 닮은 회원이 **유사도 0.45 이상**이고 **두 번째로 닮은 회원보다 0.08 이상** 앞설 때만 그 사람으로 인정해요.
- 계산은 모두 **내 브라우저 안**에서 해요(onnxruntime-web). 서버에는 **사진을 보내지도 저장하지도 않고**, 숫자 512개(특징값)만 보내요.
- 처음 한 번 얼굴 인식 파일 약 11MB를 받아요. 그다음부터는 브라우저에 보관된 파일을 써요.
- 한 번 로그인하면 그 기기에서는 자동 로그인돼요. 카메라가 없는 기기는 **내 정보 → 설정 → 로그인 코드 만들기**로 받은 8글자 코드로 로그인해요 (5분 · 한 번만).
- **카메라는 https 주소나 localhost 에서만** 켜져요 (브라우저 보안 규칙). 같은 와이파이 주소(`http://192.168…`)에서는 카메라를 쓸 수 없으니
  서버 컴퓨터에서는 `http://localhost:3000`, 친구들은 인터넷 주소(`start-online.bat` 또는 Render 주소)로 들어오면 돼요.

| 게임 기록 | 멀티: 게임별 판 수 · 승리 · 순위, 최근 경기(같이 한 사람). 싱글: 게임별 최고 기록 |

| 랭킹 | 레벨 · 멀티 승리 · 친구끼리 · 싱글 게임 최고 기록 |
| 내 정보 | 닉네임 · 아바타 바꾸기, 얼굴 다시 등록, 로그아웃, **회원 탈퇴(특징값 · 기록 바로 삭제)** |

**계정 저장 위치**: 내 컴퓨터에서 켜면 `userdata/accounts.json` 에 저장돼요 (GitHub 에는 올라가지 않아요).
Render 같은 클라우드에서는 서버를 다시 시작하면 파일이 지워지므로 **무료 PostgreSQL(Neon)** 을 연결해야 해요 → `DEPLOY.md` 의 **계정 저장소**.

**알아 둘 점**
- 얼굴 특징값은 **생체 정보**예요. 가입할 때 동의를 받고, 탈퇴하면 바로 지워요. 친구들끼리 쓰는 용도로 만들었어요.
- 얼굴 인식은 완벽하지 않아요. **아주 닮은 가족 · 쌍둥이**나 **사진**으로도 로그인될 수 있어서 중요한 정보는 저장하지 않아요.
  더 엄격하게 하려면 서버 환경 변수 `FACE_MATCH`(기본 0.45) · `FACE_MARGIN`(기본 0.08)을 올리세요.
- 얼굴 인식 모델(InsightFace buffalo_s)은 **비상업적 용도**로만 쓸 수 있어요. 돈을 받는 서비스에 쓰려면 InsightFace 쪽 라이선스를 따로 확인하세요.

## v12.2에서 바뀐 점
- **레벨 테두리** — 아바타 테두리가 10레벨마다 바뀌어요: 새싹(1) · 브론즈(10) · 실버(20) · 골드(30) · 에메랄드(40) · 사파이어(50) · 루비(60) · 자수정(70) · 다이아(80) · 레전드(90).
  골드부터 은은하게 빛나고, 에메랄드부터 테두리가 돌고, 사파이어는 점선 궤도 · 루비부터 빛 알갱이 · 자수정 · 다이아 배지 · 레전드는 무지개 테두리 + 왕관. 5레벨마다(15 · 25 …) 테두리에 작은 별이 붙어요.
  움직이는 효과는 큰 아바타(프로필 카드 · 내 정보 · 대기실 · 홈)에서만 — 목록의 작은 아바타는 가만히 있어서 눈이 편해요. 레벨 표시(Lv.)도 테두리 색이에요.
- **칭호 37개** (`public/js/shared/titles.js` — 화면과 서버가 같이 써요): 판수(단골 50 · 게임 중독 300 · **폐인 1,000** · 전설의 폐인 3,000판) · 멀티 승리 · 연승(3 · 5 · 10연승) · 싱글(AI 이기기 · 최고 기록 깨기) ·
  출석(7 · 30 · 100일 연속) · 미션 · 여러 게임 · 고스톱 「타짜」 · 체스 · 오목 · 친구 · 귓속말 · 레벨(Lv.30 · 60 · 99 「만렙」) · 한정 「원년 멤버」(2026년 가입) · 숨겨진 칭호 2개(???).
  등급: 일반 · 희귀 · 영웅 · 전설(반짝이는 금색). 한 번 받으면 계속 내 거예요. 예전 기록으로 채운 칭호는 서버를 켤 때 바로 받아요.
- **축하 화면** — 새 테두리 · 영웅 이상 칭호를 받으면 화면 가득 빛 · 반짝이 · 소리와 함께 보여 주고 바로 「달기」. 처음 한 번은 소개 화면.
  게임 중 · 결과창에서는 기다렸다가 결과창이 닫히면(대기실 · 메뉴) 떠요 — 「한 판 더」 · 대기실 버튼을 가리지 않아요. 결과창에서는 경험치 링이 새 테두리 색으로 반짝여요.
  일반 · 희귀 칭호는 오른쪽 위 알림 카드로 가볍게(「달기」 버튼). 게임이 시작되면 떠 있던 축하 화면은 닫혀요.
  친구가 새 테두리나 영웅 이상 칭호를 받으면 알림 카드가 뜨고 👏 **축하**를 보낼 수 있어요.
- **내 정보 → 칭호 탭** — 지금 내 모습 · 테두리 고르기(자동 = 레벨에 맞춰, 받은 테두리 중 골라도 돼요) · 칭호 달기 · 칭호마다 진행 막대(예: 폐인 720 / 1,000판). 단 칭호는 프로필 카드 · 대기실 · 랭킹 · 홈에 보여요.
- **경험치 링** — 결과창에서 내 아바타 테두리가 경험치 막대가 되어 차올라요(레벨 업이면 한 바퀴 채우고 새 레벨로) · 연승 중이면 「n연승 중」. 위쪽 내 아바타 · 홈 카드도 테두리가 경험치 링이에요.
- 서버: 연승 · 친구와 한 판 · 큰 판 1등 · 최고 기록 깬 횟수 · 미션 · 귓속말 수를 칭호용으로 세요(15초보다 짧은 판은 빼요). `acct:look`(꾸미기 저장) · `acct:ttlseen` · `fr:cheer` 이벤트.
- `npm test` 에 칭호 검사(`tests/titles.test.js`: 레벨 · 테두리 계산 · 모든 칭호를 서버 통계로 받을 수 있는지)를 넣었어요.

### 게임별 메모 (v7)
- **러미 타일**: 타일을 눌러 고르고(여러 개 가능) 세트 끝의 화살표나 「새 세트」를 누르면 옮겨져요. 컴퓨터에서는 끌어다 놓기도 돼요. 시간이 끝날 때 배치가 맞으면 자동으로 내려놓고, 아니면 한 장 가져가요. 대기실에서 차례 시간(30~90초 · 없음)을 골라요.
- **황야의 총잡이**: 4~7명(빈자리는 봇). 인물 능력은 원작 기본판과 같고 이름만 새로 지었어요. 자리를 누르면 그 사람 능력이 보여요. 멀티는 차례 50초 · 대응 15초.
- **궁정 음모**: 도전 · 막기는 모두가 동시에 답해요(멀티 10초, 싱글은 내 답을 기다려요). 2명이면 먼저 하는 사람은 코인 1개로 시작해요(공식 규칙).
- **계급 전쟁**: 판 수 3 · 5. 판마다 1등 (인원-1)점 … 꼴찌 0점. 판 사이 결과표는 10초 뒤 자동으로 다음 판. 멀티에서는 판마다 6초 「카드 정리」 시간이 있어요(어릿광대 2장 혁명 결정이 시간으로 티 나지 않게).
- **그림 릴레이**: 멀티 전용(3~10명). 그리고 맞히는 동안은 채팅이 잠겨요(정답 스포 방지).
- **드리프트 카트**: 트랙 3개(햇살 서킷 · 얼음 계곡 · 사막 하이웨이) · 스피드전/아이템전 · 1/2/3/5바퀴. 싱글은 AI 7대, 멀티는 최대 8명. 휴대폰에서는 화면이 달리는 방향으로 돌아가고 터치 버튼(브레이크 · 드리프트 · 아이템, 자동 가속)이 나와요. 1등이 골인하면 남은 사람은 20초 안에 들어와야 해요.

## 새 게임을 추가하려면
- 서버: `games/새게임.js`를 만들고 `server.js`의 `MODULES` 목록에 이름을 넣습니다.
- 화면: `public/js/새게임.js`에서 `makeScreen('새게임', {...})`으로 화면을 만들고 `register('새게임', { solo, multi, stop, key, keyup, pad })`로 등록한 뒤, `index.html`에 `<script>` 줄을 추가합니다.
- 메뉴: `core.js`의 `GAME_INFO`(멀티) / `SOLO_GAMES`(싱글)에 한 줄을 추가합니다.
- 설명서: `public/js/manual/새게임.js` 에 `Manual.add('새게임', { level, time, goal, core, controls, detail, tips, mistakes })` 를 만들어요 (형식은 다른 게임 파일 참고).
- 따라 하기(선택): `public/js/tutorial/새게임.js` 에 `Tutorial.add(...)` 각본을 만들고 `tutorial.js` 의 `LIST` 에 키를 넣어요 (차례형 게임만, 고스톱 각본 참고).
- 기록: 멀티는 `H.finishGame` 의 결과표(`ranking`) 1등이 자동으로 승리로 기록돼요. 팀 게임처럼 이긴 사람이 여럿이면 `winners: [id, …]` 를 같이 넘겨요.
  싱글은 `showResult({ …, solo: '키', win: true/false, rec: { v: 점수 } })` 처럼 결과를 넘기고, `lib/accounts.js` 의 `SOLO_KEYS` 에 키를 넣어요.

### 차례형 보드·카드 게임 추가하기 (TableKit)
1. `public/js/shared/새게임-core.js` 에 규칙을 만들어요: `meta` · `setup` · `view`(사람마다 보이는 정보) · `act`(행동, 틀리면 안내 문장 반환) · `pending`(행동할 사람) · `ai`(봇) · `result`.
   시간으로 넘어가는 단계가 있으면 `deadline` / `timeup`, 일부에게만 채팅을 보내려면 `chatRoute` (마피아 참고).
2. `games/table.js` 의 목록에 이름을 넣으면 멀티(봇 포함)가 바로 돼요.
3. 화면은 `public/js/새게임.js` 에서 `Table.def('새게임', { core, render(view, ctx), solo })` — 싱글(봇 대전)도 같은 규칙 파일로 돌아가요.
