# 미니게임 천국

친구들과 함께 하는 미니게임 모음입니다. 혼자 하는 게임 36종과 같이 하는 게임 43종이 들어 있어요.
(같은 와이파이는 물론, `start-online.bat` 으로 인터넷 주소를 만들면 다른 곳의 친구와도 할 수 있어요.)

## 실행 방법
1. Node.js(LTS)를 설치합니다: https://nodejs.org
2. `start.bat`을 더블클릭합니다. 처음 실행할 때는 필요한 부품을 자동으로 설치합니다.
3. 브라우저에서 `http://localhost:3000`을 엽니다. 친구는 서버 창에 나온 "같은 와이파이" 주소로 들어오면 됩니다.

### 🌍 다른 곳에 있는 친구와 하기
- **`start-online.bat`** 을 더블클릭하면 `https://xxxx.trycloudflare.com` 같은 인터넷 주소가 생겨요. 이 주소는 어디서든(다른 와이파이, 휴대폰 데이터) 들어올 수 있어요.
- 컴퓨터를 꺼도 되는 **고정 사이트**가 필요하면 Render 무료 서버에 올리세요.
- 두 방법 모두 **[DEPLOY.md](DEPLOY.md)** 에 순서대로 적어 두었어요.
- 대기실의 **📋 초대 링크 복사** 버튼으로 받은 링크를 친구가 누르면 그 방으로 바로 들어와요.

## v7에서 바뀐 점
- 새 게임 6종 — 규칙은 보내 주신 나무위키 문서를 기준으로 만들었어요.
  - **러미 타일**: 106개 타일 · 런/그룹 · 첫 등록 30점(내 타일로만) · 등록 뒤 바닥 세트 자유 재배치 · 조커 · 차례 시간(시간이 끝날 때 맞는 배치면 자동으로 내려놓기) · 남은 타일 벌점(조커 30)
  - **황야의 총잡이**: 기본판 카드 80장(무늬 · 숫자까지) · 역할 4종 · 인물 16명 · 거리와 사정거리 · 술통/감옥/다이너마이트 카드 펼치기 · 결투 · 잡화점 · 무법자 현상금 · 보안관이 부관을 쏘면 벌칙
  - **궁정 음모 · 계급 전쟁 · 그림 릴레이 · 드리프트 카트**: 아래 「게임별 메모」 참고
- **암호 해독**(다빈치 코드 방식): 규칙서대로 **조커(−)** 를 색마다 1장씩 추가 — 시작 패엔 없고, 뽑으면 원하는 자리에 놓아요. 상대 타일을 「조커」라고 맞힐 수도 있어요.
- **요트 다이스**: 세계 게임 전집 51 규칙대로 **요트(5개 같음)도 풀 하우스**로 인정
- 대기실 게임 옵션(봇 수 · 차례 시간 등)의 기본값이 방을 만들 때부터 적용돼요
- 차례형 게임에서 시간 초과로 한 번 대신 둔 사람은 다시 직접 할 때까지 짧게(5초) 기다려요 — 자리를 비운 사람 때문에 판이 늘어지지 않게
- 남은 시간은 서버 시계 기준으로 보여 줘요 (휴대폰 시계가 틀려도 정확)
- 원작의 상표 · 인물 이름 대신 새 이름을 붙였어요 (규칙은 그대로)
- 메뉴 표시: **NEW** = v7 새 게임, **UP** = 규칙을 고친 게임

### 게임별 메모 (v7)
- **러미 타일**: 타일을 눌러 고르고(여러 개 가능) 세트 끝의 화살표나 「새 세트」를 누르면 옮겨져요. 컴퓨터에서는 끌어다 놓기도 돼요. 시간이 끝날 때 배치가 맞으면 자동으로 내려놓고, 아니면 한 장 가져가요. 대기실에서 차례 시간(30~90초 · 없음)을 골라요.
- **황야의 총잡이**: 4~7명(빈자리는 봇). 인물 능력은 원작 기본판과 같고 이름만 새로 지었어요. 자리를 누르면 그 사람 능력이 보여요. 멀티는 차례 50초 · 대응 15초.
- **궁정 음모**: 도전 · 막기는 모두가 동시에 답해요(멀티 10초, 싱글은 내 답을 기다려요). 2명이면 먼저 하는 사람은 코인 1개로 시작해요(공식 규칙).
- **계급 전쟁**: 판 수 3 · 5. 판마다 1등 (인원-1)점 … 꼴찌 0점. 판 사이 결과표는 10초 뒤 자동으로 다음 판. 멀티에서는 판마다 6초 「카드 정리」 시간이 있어요(어릿광대 2장 혁명 결정이 시간으로 티 나지 않게).
- **그림 릴레이**: 멀티 전용(3~10명). 그리고 맞히는 동안은 채팅이 잠겨요(정답 스포 방지).
- **드리프트 카트**: 트랙 3개(햇살 서킷 · 얼음 계곡 · 사막 하이웨이) · 스피드전/아이템전 · 1/2/3/5바퀴. 싱글은 AI 7대, 멀티는 최대 8명. 휴대폰에서는 화면이 달리는 방향으로 돌아가고 터치 버튼(브레이크 · 드리프트 · 아이템, 자동 가속)이 나와요. 1등이 골인하면 남은 사람은 20초 안에 들어와야 해요.

```

lib/util.js             공통 도구 (난수, 섞기, 이름 정리 등)
lib/helpers.js          게임들이 함께 쓰는 서버 기능 (점수판, 결과창, 대기실 복귀, 타이머)
lib/tunnel.js           인터넷 공개용 Cloudflare 무료 터널 (start-online.bat)
render.yaml             Render 무료 클라우드 서버 설정
data/words.js           캐치마인드·라이어·산성비 단어 목록
data/quiz.js            OX 퀴즈 문제
games/*.js              서버 쪽 게임 규칙 (게임 하나에 파일 하나)
public/index.html       화면 뼈대
public/style.css        디자인 (기본 다크 모드)
public/js/core.js       화면 전환·대기실·채팅·결과창·키보드·게임 목록
public/js/*.js          화면 쪽 게임 코드 (게임 하나에 파일 하나)
public/js/shared/*.js   화면과 서버가 함께 쓰는 게임 엔진 (배구 물리 · 폭탄 배틀 · 탱크 · 보드·카드 게임 규칙)
public/js/shared/table.js  차례형 보드·카드 게임 공통 진행기 (TableKit: 봇 · 시간 제한 · 숨긴 정보)
games/table.js          보드·카드 게임을 서버에서 돌리는 곳 (빈자리는 봇, 나간 사람은 봇이 대신)
public/css/board.css    보드·카드 게임 디자인 (v7 게임은 public/css/게임.css 따로)
public/js/icons.js      아이콘 (Tabler Icons, MIT)
public/fonts/           제목 글꼴 Black Han Sans (SIL OFL 1.1, 인터넷이 없어도 보여요)
```

## 새 게임을 추가하려면
- 서버: `games/새게임.js`를 만들고 `server.js`의 `MODULES` 목록에 이름을 넣습니다.
- 화면: `public/js/새게임.js`에서 `makeScreen('새게임', {...})`으로 화면을 만들고 `register('새게임', { solo, multi, stop, key, keyup, pad })`로 등록한 뒤, `index.html`에 `<script>` 줄을 추가합니다.
- 메뉴: `core.js`의 `GAME_INFO`(멀티) / `SOLO_GAMES`(싱글)에 한 줄을 추가합니다.

### 차례형 보드·카드 게임 추가하기 (TableKit)
1. `public/js/shared/새게임-core.js` 에 규칙을 만들어요: `meta` · `setup` · `view`(사람마다 보이는 정보) · `act`(행동, 틀리면 안내 문장 반환) · `pending`(행동할 사람) · `ai`(봇) · `result`.
   시간으로 넘어가는 단계가 있으면 `deadline` / `timeup`, 일부에게만 채팅을 보내려면 `chatRoute` (마피아 참고).
2. `games/table.js` 의 목록에 이름을 넣으면 멀티(봇 포함)가 바로 돼요.
3. 화면은 `public/js/새게임.js` 에서 `Table.def('새게임', { core, render(view, ctx), solo })` — 싱글(봇 대전)도 같은 규칙 파일로 돌아가요.
